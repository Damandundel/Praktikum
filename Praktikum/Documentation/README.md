# Документация – Praktikum

**Дипломен проект:** Система за управление на ученически стажове и практическо обучение „Praktikum“
**Автор:** Дамян Георгиев, 12В клас · ЧПГДН „СофтУни Будител“ · специалност „Приложно програмиране“
**Ръководител-консултант:** Иванжела Динчева

Документацията се качва поетапно. Всеки етап добавя нови файлове; това са работните материали в Markdown,
а официалният документ по шаблона на училището е [Diplomen-proekt-Praktikum.docx](Diplomen-proekt-Praktikum.docx).
